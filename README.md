# SafeInspect Mobile

## Descripción

SafeInspect Mobile es una aplicación móvil desarrollada con Flutter y Firebase para optimizar el registro y seguimiento de inspecciones de seguridad industrial.

## Tecnologías

- Flutter
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- GitHub

## Arquitectura

La aplicación utiliza una arquitectura cliente-servidor donde Flutter consume los servicios de Firebase para autenticación, almacenamiento de datos y gestión de evidencias fotográficas.

## Objetivo

Desarrollar una aplicación móvil que reduzca el tiempo de registro de inspecciones y mejore la trazabilidad de la información.
